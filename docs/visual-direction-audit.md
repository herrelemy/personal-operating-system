# Visual Direction Audit — أبا غالية وآمنه

## خلاصة التدقيق

الواجهة الحالية تستخدم قاعدة داكنة شبكية مع تدرجات سماوية جيدة، لكن الاعتماد على الخلفية نفسها في معظم الصفحات يقلل الإحساس بشخصية كل مساحة. سيحافظ التصميم الجديد على الطابع الهادئ والموثوق، ويضيف طبقات ضوء وتصويرًا تحريريًا محدودًا داخل المساحات الأعلى أولوية بدل الصور الزخرفية العشوائية. سيبقى اللون الأزرق الكهربائي هو الرابط الرئيسي بين التطبيق والموقع، بينما تستخدم ألوان المجالات بوصفها إشارات دلالية لا كهوية متنافسة.

| النظام | القرار البصري |
| --- | --- |
| اللون الأساسي | كحلي حبرّي عميق مع أزرق أثيري مضيء للـ CTA والحالات النشطة، مدعوم بضباب أزرق بارد. |
| ألوان المجالات | تركواز للإنجاز والعادات، زمردي للماليات، عنبري للأفكار والملاحظات، وردي هادئ للذكريات، بنفسجي-أزرق للتعلّم، أخضر صنوبر للعبادة. |
| الخلفيات | سطح عام قاتم قليل الضوضاء، مع هالة ضوء وتصوير/نقش خافت خاص بكل مساحة؛ لا تتداخل الخلفيات مع النص أو التحكم. |
| الكتابة | Alexandria للنص العربي والواجهات، وNoto Naskh Arabic للمحتوى القرآني؛ تدرج وزني واضح وعناوين أقصر ذات كثافة أعلى. |
| الأيقونات | Lucide بخط موحّد، داخل حاويات دائرية زجاجية ذات ألوان مجال مضبوطة؛ لا أيقونات مرسومة بأساليب متباينة. |
| البطاقات | طبقة زجاجية داكنة مضبوطة، حافة رفيعة، ظل عميق واحد، Radius موحّد، ولمعة داخلية خفيفة فقط في البطاقات ذات الأولوية. |
| الحركة | انتقالات opacity/transform في نطاق 120–240ms، ضغط 0.97، واحترام تقليل الحركة؛ لا دخول استعراضي أو حركة تؤثر في القراءة. |

## خريطة الأقسام

| القسم والمسار | اللون والـ Background | الصورة أو المعالجة البصرية | الأيقونات وطريقة العرض |
| --- | --- | --- | --- |
| الرئيسية `/` | كحلي + سماوي، خلفية ليلية ذات مدار ضوئي | صورة عمودية تحريرية لمحطة عمل هادئة مع مساحة نص آمنة إلى اليمين، Overlay داكن متدرج | بطاقات ملخصات صغيرة، ثم Grid لمجالات الحياة مع ألوان مجالية متزنة. |
| المهام `/tasks` والمشاريع `/projects` | أزرق-فحمي مع خيوط تركيز | صورة تجريدية منظمة لسطح تخطيط/أوراق بدون نص داخل Hero صغير | CheckSquare وFolderKanban داخل شارات سماوية؛ قوائم العمل تبقى عملية بكثافة منخفضة. |
| العادات `/habits` والتحليلات `/analytics` | تركواز داكن مع ضوء صباحي | تدرج عضوي مع دوائر تقدم؛ لا صورة فوتوغرافية كي تبقى البيانات محورًا | Flame, Trophy, ChartLine داخل حالات تقدم واضحة؛ metrics تختار العلاج الأقوى. |
| الماليات `/finance` | زمردي داكن مع لمعة ذهبية خافتة | مشهد مكتبي مالي/دفتر حسابات مجرد بنسب عمودية، مع مساحة أزرار واضحة | Wallet, ArrowUpRight, Receipt داخل شارات زمردية/وردية متوازنة؛ الرسوم لا تتأثر بالخلفية. |
| المواعيد `/calendar` | أزرق ضبابي هادئ | ضوء تقويمي مرسوم وخطوط زمنية خفيفة؛ لا صورة تتنافس مع الأيام | Calendar, Clock, MapPin؛ مساحة التقويم بيضاء نسبيًا داخل بطاقة عالية التباين. |
| الملاحظات `/notes` | عنبري دخاني مع ملمس ورقي دقيق | لقطة عمودية لأوراق وخطوط/فكرة مضاءة، مقصوصة بعيدًا عن خانة البحث | NotebookPen وLightbulb؛ قائمة الأفكار بطاقة-تلو-بطاقة مع أولوية للحالة الفارغة. |
| عبادتي `/spiritual` | أخضر صنوبر + فيروزي هادئ | نقش معماري إسلامي تجريدي غير نصّي ونور هادئ في الخلفية | BookOpen, Heart, Moon, HandsPraying؛ المحتوى القرآني يحصل على فراغ أكبر وخلفية أصفى. |
| مساعدي `/assistant` ومهمة صوتية `/voice-task` | أزرق كهربائي مع بنفسجي تقني خفيف | كوكبة نقاط/تدفق صوتي تجريدي، وليس شخصية أو روبوتًا | Bot, Sparkles, Mic؛ منطقة الكتابة أكثر حضورًا وحالات الاستماع مرئية دون حركة مشتتة. |
| ذكريات `/memories` | وردي غباري + برقوقي | صورة عمودية لطاولة ذكريات/صور بولارويد بلا وجوه محددة، بدرجة فيلم موحّدة | Images, Heart, Calendar؛ إضافة الذكرى تأخذ معالجة Story-like آمنة للنص. |
| Deutsch lernen `/deutsch` | بنفسجي-أزرق مع كهرماني محدود | صورة عمودية لدفتر تعلّم ولغة مع معلم ألماني مجرد غير نصي | GraduationCap, BookOpen, Trophy؛ الخطة تظهر كمسار متتابع قابل للمس. |
| المحتوى الاجتماعي `/social` | سماوي-نيلي مع مرجان محدود | مصفوفة منشورات تجريدية/كاميرا وميكروفون كتصوير فني بدون شعارات منصات مولّدة | Share2, Calendar, Lightbulb؛ المحتوى يبقى في وحدات قابلة للفلترة بلا ازدحام. |
| خزانة كلمات المرور `/vault` | فحمي مع أزرق فولاذي | لا صورة فوتوغرافية؛ نقش قفل هندسي وتأثير معدني خافت لتعزيز الثقة | LockKeyhole, ShieldCheck, KeyRound؛ واجهة شديدة الهدوء وتباين أعلى للنماذج. |
| مساحتي `/more` | كحلي محايد يجمع الألوان الفرعية | فسيفساء ضوئية مجردة تربط المجالات بدل صور مختلفة | أيقونات المجالات ضمن بطاقات تنقل واضحة مع مؤشرات قصيرة للحالة. |

## قواعد الموبايل

سيتم اعتماد واجهات Mobile-first بقياس لمس أدنى 44px، مع صور عمودية قريبة من 9:16 في الـ Hero أو خلفياتها فقط. تحافظ طبقات التعتيم المتدرجة على سلامة العنوان والأزرار، وتتحول الصور إلى خلفية داخلية أو Banner قصير عند ضيق المساحة. ستبقى القوائم والـ Cards في عمود واحد عند الحاجة، وتُمنع أي حواف زخرفية أو عناصر absolute قد تسبب تمريرًا أفقيًا.
