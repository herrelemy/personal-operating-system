# Production Test Notes

## Local smoke test — 2026-08-14

تم تحميل الصفحة الرئيسية بنجاح على `http://localhost:5173/` مع اتجاه RTL، الترويسة، الشريط الجانبي، الإحصاءات، الخط الزمني، ومجالات الحياة. لم يظهر خطأ تحميل أو مسار Manus داخل الصفحة.

تم الانتقال من الصفحة الرئيسية إلى `/tasks` عبر زر التنقل الجانبي دون إعادة تحميل كامل، وظهرت قائمة المهام مع المرشحات والإجراء `مهمة جديدة`. حالة المهمة المنجزة ظهرت بصريًا، ما يؤكد أن الحالة المحلية تُقرأ وتُعرض.

## Forms

تم فتح نموذج `مهمة جديدة` من المسار `/tasks`، وظهر الحقل النصي والقائمة المنسدلة وزر الحفظ. تم إدخال `مراجعة النسخة النهائية` بنجاح، ولم يحدث فقدان للنص أو خطأ مرئي.

## Persistence and navigation

تم حفظ المهمة التجريبية بنجاح؛ أُغلق النموذج وظهرت المهمة الجديدة في أعلى القائمة مع إشعار `أضيفت المهمة إلى يومك`. تم الانتقال بعد ذلك إلى `/finance` وظهرت بطاقات الرصيد والدخل والمصروف وقائمة الحركات دون أخطاء مرئية.

## Finance form

تم فتح نموذج `إضافة مصروف`، وإدخال `مواصلات` بمبلغ `42` وتصنيف `تنقل`، ثم حفظه بنجاح. أُغلق النموذج، ظهر إشعار `تم حفظ الحركة المالية`، وتحدّث الرصيد من 263 إلى 221 ج.م والمصروف من 87 إلى 129 ج.م.

## Theme and calendar

تم تبديل المظهر إلى الوضع النهاري بنجاح مع بقاء المحتوى والبطاقات مقروءة. تم الانتقال إلى `/calendar`، وظهرت شبكة شهر أغسطس 2026 وقائمة المواعيد القادمة، بما يثبت عمل المسار في الوضع النهاري.

## Runtime and direct-route smoke test

أظهر Console رسائل React DevTools المعلوماتية فقط دون أخطاء `error` أو تحذيرات Runtime. تم تحميل `/habits` مباشرة عبر URL، وظهرت صفحة العادات والغلاف الكامل، ما يدعم عمل إعادة كتابة SPA عند التحديث.

## External delivery verification

تم رفع المستودع إلى [GitHub](https://github.com/herrelemy/personal-operating-system) على فرع `main`، وظهر README والمجلدان `src` و`public/fonts` وملفات الإعداد في الواجهة العامة. أنشأ Vercel مشروعًا باسم `aba-ghalia-amina-web-live` وأعاد رابط Deployment إنتاجي، لكن الوصول العام من المتصفح أعاد إلى تسجيل الدخول في Vercel، كما تعذر إنشاء رابط مشاركة مؤقت. في المقابل، الرابط العام الظاهر في About داخل GitHub، [personal-operating-system-ioqb.vercel.app](https://personal-operating-system-ioqb.vercel.app)، يعمل ويعرض الصفحة الرئيسية والتطبيق العربي دون تسجيل دخول؛ وهو رابط Vercel العام المتاح حاليًا للاستخدام والاختبار.

تم تحميل `/tasks` مباشرة في الإنتاج وظهرت صفحة المهام مع التصفية والمهام الافتراضية. وتم تحميل `/finance` مباشرة وظهرت بطاقات الرصيد والدخل والمصروف والحركات الأخيرة، دون ظهور 404 أو صفحة خطأ.

تم فتح نموذج إضافة مصروف في `/finance`، ونجحت تعبئة الوصف والمبلغ والتصنيف بقيم اختبار غير حساسة؛ زر الحفظ ظهر في النموذج وجاهز للتحقق من دورة الإرسال.

تم حفظ الحركة بنجاح في الإنتاج، وظهر إشعار النجاح وتحدّث الرصيد من 263 إلى 262 ج.م وإجمالي المصروف من 87 إلى 88 ج.م، مع ظهور الحركة الجديدة في القائمة. كما تم تحميل `/calendar` مباشرة، وظهرت شبكة أغسطس 2026 وقائمة المواعيد القادمة دون 404.

فحص HTTP النهائي أعاد `200` للصفحة الرئيسية والمسارات `/tasks` و`/calendar` و`/finance` و`/habits`، وحمّل HTML أصول JavaScript وCSS المجمعة. GitHub يعرض commit `5d60d54` على `main`، وشجرة العمل المحلية نظيفة، ولا توجد ملفات أسرار أو مخرجات بناء ضمن الأرشيف.
