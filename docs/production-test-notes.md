# Production Test Notes

## Local smoke test — 2026-08-14

تم تحميل الصفحة الرئيسية بنجاح على `http://localhost:5173/` مع اتجاه RTL، الترويسة، الشريط الجانبي، الإحصاءات، الخط الزمني، ومجالات الحياة. لم يظهر خطأ تحميل أو مسار Manus داخل الصفحة.

تم الانتقال من الصفحة الرئيسية إلى `/tasks` عبر زر التنقل الجانبي دون إعادة تحميل كامل، وظهرت قائمة المهام مع المرشحات والإجراء `مهمة جديدة`. حالة المهمة المنجزة ظهرت بصريًا، ما يؤكد أن الحالة المحلية تُقرأ وتُعرض.

## Forms

تم فتح نموذج `مهمة جديدة` من المسار `/tasks`، وظهر الحقل النصي والقائمة المنسدلة وزر الحفظ. تم إدخال `مراجعة النسخة النهائية` بنجاح، ولم يحدث فقدان للنص أو خطأ مرئي.

## Persistence and navigation

تم حفظ المهمة التجريبية بنجاح؛ أُغلق النموذج وظهرت المهمة الجديدة في أعلى القائمة مع إشعار `أضيفت المهمة إلى يومك`. تم الانتقال بعد ذلك إلى `/finance` وظهرت بطاقات الرصيد والدخل والمصروف وقائمة الحركات دون أخطاء مرئية.

## Finance form

تم فتح نموذج `إضافة مصروف`، وإدخال `مواصلات` بمبلغ `42` وتصنيف `تنقل`، ثم حفظه بنجاح. أُغلق النموذج، ظهر إشعار `تم حفظ الحركة المالية`، وتحدّث الرصيد من 263 إلى 221 ج.م والمصروف من 87 إلى 129 ج.م.

## Theme and calendar

تم تبديل المظهر إلى الوضع النهاري بنجاح مع بقاء المحتوى والبطاقات مقروءة. تم الانتقال إلى `/calendar`، وظهرت شبكة شهر أغسطس 2026 وقائمة المواعيد القادمة، بما يثبت عمل المسار في الوضع النهاري.

## Runtime and direct-route smoke test

أظهر Console رسائل React DevTools المعلوماتية فقط دون أخطاء `error` أو تحذيرات Runtime. تم تحميل `/habits` مباشرة عبر URL، وظهرت صفحة العادات والغلاف الكامل، ما يدعم عمل إعادة كتابة SPA عند التحديث.
