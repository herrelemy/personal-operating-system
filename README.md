# أبا غالية وآمنه — مساحة الحياة

نسخة Web مستقلة من **مساحة الحياة**، وهي واجهة عربية RTL هادئة لإدارة المهام والمواعيد والماليات والعادات والملاحظات والعبادات والذكريات والتعلّم. المشروع مبني ليعمل خارج Manus، ولا يعتمد على قاعدة بيانات أو API خارجي في النسخة الحالية؛ تحفظ النماذج والبيانات المحلية في `localStorage` داخل المتصفح.

## ما الذي يتضمنه المشروع؟

تتضمن الحزمة مصدر React وTypeScript كاملًا، مكوّن الغلاف والتنقل، الصفحات الأساسية، نظام المظهر الليلي والنهاري، نماذج المهام والحركات المالية، الأصول الخطية المحلية، إعداد Vite، إعداد إعادة كتابة مسارات SPA في Vercel، نموذج البيئة، واختبارًا وحديًا لطبقة التخزين المحلية.

| الجزء | المسار أو الملف | الغرض |
| --- | --- | --- |
| نقطة التشغيل | `src/main.tsx` | تهيئة React واتجاه RTL |
| التطبيق والمسارات | `src/App.tsx` | ربط المسارات والغلاف ومعالجة الأخطاء |
| الغلاف والتنقل | `src/components/LifeShell.tsx` | الشريط الجانبي والترويسة والإجراءات العامة |
| الصفحات | `src/pages/Pages.tsx` | صفحات الرئيسية والمهام والمواعيد والماليات والمزيد |
| التخزين المحلي | `src/lib/store.ts` | قراءة وكتابة البيانات دون خادم |
| المظهر | `src/contexts/ThemeContext.tsx` | تبديل الوضع الليلي والنهاري وحفظه محليًا |
| التصميم | `src/index.css` | الألوان والبطاقات والاستجابة والمكونات البصرية |
| الخطوط | `public/fonts/` | Alexandria وDM Mono وNoto Naskh Arabic محليًا |
| النشر | `vercel.json` | إعداد Vercel وSPA rewrites |

## التشغيل المحلي

يتطلب المشروع Node.js حديثًا وpnpm. بعد استنساخ المستودع، شغّل الأوامر التالية:

```bash
pnpm install --frozen-lockfile
pnpm dev
```

ثم افتح العنوان الذي يظهره Vite، وغالبًا يكون `http://localhost:5173`.

## بوابة الجودة

قبل كل نشر، شغّل الاختبارات وفحص TypeScript وبناء الإنتاج:

```bash
pnpm test
pnpm check
pnpm build
```

ويُعرض ناتج البناء داخل مجلد `dist/`. ويمكن معاينته محليًا باستخدام:

```bash
pnpm preview
```

## إعدادات Vercel

الإعداد الموصى به هو ربط مستودع GitHub مباشرة بمشروع Vercel أو استيراد المستودع من لوحة Vercel. الإعدادات الموجودة في `vercel.json` هي:

| الإعداد | القيمة |
| --- | --- |
| Framework Preset | Vite |
| Install Command | `pnpm install --frozen-lockfile` |
| Build Command | `pnpm build` |
| Output Directory | `dist` |
| SPA Rewrite | كل المسارات إلى `/index.html` |

لا يحتاج الإصدار الحالي إلى متغيرات سرية أو مفاتيح API كي يعمل. يوجد `.env.example` لتوثيق اسم التطبيق ونقاط التوسعة الاختيارية مستقبلًا. لا تضع أي قيمة سرية في متغير يبدأ بـ `VITE_`؛ القيم بهذا الشكل تصل إلى المتصفح عند البناء.

## البيانات والخصوصية

هذه النسخة **محلية بالكامل** من ناحية البيانات. المهام والمواعيد والحركات المالية والمظهر تُحفظ في متصفح المستخدم عبر `localStorage` ولا تُرسل إلى خادم. لذلك لا يوجد تسجيل دخول أو مزامنة بين الأجهزة أو API إنتاجي في هذه الحزمة. إذا أُضيفت مزامنة مستقبلًا، يجب إضافة خادم آمن ومتغيرات بيئة سرية خارج المستودع.

## المسارات الأساسية

يعمل التطبيق عبر المسارات التالية، مع دعم التحميل المباشر والتحديث بفضل إعداد Vercel:

`/`، `/tasks`، `/calendar`، `/finance`، `/habits`، `/notes`، `/spiritual`، `/memories`، `/assistant`، و`/deutsch`.

## مبادئ النقل خارج Manus

لا يحتوي المستودع على مفاتيح API أو كلمات مرور أو Access Tokens أو ملفات APK أو أرشيفات مستعادة أو مخرجات بناء. كل ما يلزم لتشغيل نسخة Web موجود في المصدر و`package.json` و`pnpm-lock.yaml` و`public/fonts` وملفات إعداد Vite/Vercel. يمكن تشغيله محليًا أو عبر Vercel أو أي استضافة Static SPA تدعم إعادة كتابة المسارات إلى `index.html`.

## الترخيص

الواجهة مخصصة للاستخدام الشخصي. ملف `package.json` يضع ترخيص الحزمة البرمجية على MIT؛ راجع حقوق أي أصول خارجية قبل إعادة التوزيع التجاري.
